# ProScreen Recorder - Professional Screen & Voice Recording

A modern, professional web-based screen and voice recording application with advanced features, beautiful animations, and an intuitive user interface.

## ✨ Features

### 🎥 Recording Modes
- **Screen Recording**: Capture your entire screen or specific applications
- **Voice Recording**: High-quality audio recording with noise suppression
- **Dual Audio Support**: Record system audio, microphone, or both simultaneously

### 🎨 Modern UI/UX
- **Fixed Control Panel**: Always accessible recording controls at the bottom
- **Animated Landing Page**: Beautiful animations and floating elements
- **Responsive Design**: Works perfectly on desktop, tablet, and mobile
- **Professional Design**: Modern gradient backgrounds and smooth transitions

### 🔧 Advanced Features
- **Real-time Transcription**: Automatic speech-to-text in multiple languages
- **Multiple Export Formats**: Download as video (WebM) or transcription (Word)
- **Recording Timer**: Live recording duration display
- **Pause/Resume**: Full control over recording sessions
- **High-Quality Output**: Optimized video and audio settings

## 🚀 Getting Started

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Microphone and camera permissions (for voice recording)
- Screen sharing permissions (for screen recording)

### Installation
1. Clone or download the repository
2. Open `index.html` in your web browser
3. Grant necessary permissions when prompted
4. Start recording!

## 📱 How to Use

### Screen Recording
1. Select "Screen" mode from the control panel
2. Choose your audio source (System, Microphone, or Both)
3. Click "Start Screen Recording"
4. Select the screen or application to record
5. Click "Stop" when finished
6. Download your recording

### Voice Recording
1. Select "Voice" mode from the control panel
2. Choose your audio source
3. Click "Start Voice Recording"
4. Speak clearly into your microphone
5. Click "Stop" when finished
6. Download your audio file

### Transcription
- Real-time transcription appears during recording
- Download transcription as a Word document
- Supports multiple languages for accurate transcription

## 🎯 Key Features Explained
